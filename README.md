🎬 Cinema Ticket Reservation & Management System | C++

I developed a console-based Cinema Ticket Reservation & Management System using C++, simulating the core workflow of a real-world cinema booking system.

✨ Key Features:
• 🎞️ Display currently available movies
• 🔎 Search for movie details
• 🎫 Book multiple tickets
• 💺 Track and update available seats
• 🧾 Generate booking confirmation
• 🔢 Generate a unique Booking ID
• 🔍 Search and view booking details
• ❌ Cancel bookings and restore available seats
• 📋 View all active bookings
• 💰 Automatically calculate the total ticket price
• ⚠️ Validate movie selection, ticket quantity, and seat availability

🛠️ Technologies & Concepts:
C++ | Arrays | Loops | Conditions | Strings | User Input | Data Management | Problem Solving | Business Logic

💡 This project allowed me to practice transforming a real-world cinema reservation workflow into a functional application, while strengthening my C++ fundamentals and problem-solving skills before moving into OOP.
